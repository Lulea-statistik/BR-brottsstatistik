Metod & data

Rapporten bygger på Brå:s årsvisa kommunstatistik över anmälda brott. Data lagras årsvis i Parquet och läses direkt i webbläsaren med DuckDB-Wasm.

Årskartan använder kommunpolygoner som i första hand byggs från SCB:s öppna geodata. Om den hämtningen misslyckas används en förenklad reservgeometri enbart för visualisering.
